# Опис Проєкту: Індексатор та Пошуковик Коду

Цей проєкт є інструментом для **індексації та семантичного пошуку по кодовій базі**. Він дозволяє розробникам шукати фрагменти коду не просто за ключовими словами, а за їхнім змістом та призначенням.

### Як це працює?

Процес можна розділити на кілька ключових етапів:

1.  **Парсинг коду**: Інструмент використовує бібліотеку `tree-sitter` для аналізу синтаксичної структури вихідного коду. Це дозволяє йому "розуміти" код на глибшому рівні, розрізняючи функції, класи, змінні та інші мовні конструкції. Проєкт вже налаштований для роботи з Python, Go та Kotlin, як видно з файлів у директорії `vendor/`.

2.  **Створення векторних представлень (Embeddings)**: Після парсингу кожен значущий фрагмент коду (наприклад, функція або клас) перетворюється на числовий вектор за допомогою попередньо навченої моделі машинного навчання (`all-MiniLM-L6-v2`, що знаходиться в папці `models/`). Цей вектор представляє семантичне значення коду.

3.  **Індексація**: Отримані вектори разом із метаданими (наприклад, шлях до файлу та номер рядка) зберігаються у спеціальному індексі (ймовірно, у файлі `.code-index/entities.json`). Цей індекс оптимізовано для швидкого та ефективного пошуку. Скрипт `search_index.py` відповідає за створення та оновлення цього індексу.

4.  **Пошук**: Коли користувач вводить пошуковий запит (наприклад, "функція для читання файлу"), цей запит також перетворюється на вектор. Система порівнює вектор запиту з векторами в індексі й знаходить найбільш близькі (релевантні) фрагменти коду.

5.  **Інтеграція з LLM**: Присутність файлу `src/providers/llm_ollama.py` свідчить про можливість інтеграції з великими мовними моделями (LLM) через сервіс Ollama. Це може використовуватися для більш складних завдань, таких як відповіді на питання про код, автоматична генерація документації або навіть рефакторинг.

### Основні компоненти:

*   **`main.py`**: Головний файл, що запускає програму.
*   **`search_index.py`**: Скрипт для створення пошукового індексу.
*   **`src/`**: Директорія з основною логікою (парсер, робота з embeddings, конфігурація).
*   **`models/`**: Містить модель для створення векторних представлень.
*   **`vendor/`**: Містить парсери `tree-sitter` для підтримки різних мов програмування.

### Інструкція з використання Code Indexer

Ця інструкція пояснює, як налаштувати та використовувати інструмент для індексації та пошуку у вашій кодовій базі.

#### Крок 1: Встановлення та налаштування

Перед початком роботи необхідно встановити всі залежності та скомпілювати мовні парсери.

1.  **Встановіть залежності Python:**
    Переконайтеся, що у вас активоване віртуальне середовище, і виконайте команду:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Скомпілюйте мовні бібліотеки:**
    Ця команда створить файл `build/my-languages.so`, необхідний для аналізу коду.
    ```bash
    python3 build_langs.py
    ```
    *Примітка: Переконайтеся, що директорія `vendor/` містить вихідний код парсерів для `python`, `kotlin` та `go`. Якщо ні, їх потрібно завантажити, як вказано в `README.md`.*

3.  **(Опційно) Завантажте ONNX модель:**
    Якщо ви плануєте використовувати інструмент на пристроях з обмеженими ресурсами (наприклад, мобільних), завантажте оптимізовану модель:
    ```bash
    python3 download_onnx.py
    ```

#### Крок 2: Індексація кодової бази

Процес індексації складається з кількох послідовних етапів. Виконуйте їх по черзі.

1.  **Сканування (`scan`):**
    Інструмент аналізує файли у вказаній директорії та виділяє з них основні структурні елементи (функції, класи). Замініть `/path/to/your/project` на шлях до вашого проєкту.
    ```bash
    python3 main.py scan /path/to/your/project
    ```

2.  **Аналіз коду (`intents` та `summarize`):**
    На цьому етапі інструмент за допомогою локального LLM (потрібен запущений **Ollama**) аналізує призначення коду.
    ```bash
    python3 main.py intents
    python3 main.py summarize
    ```

3.  **Створення векторів (`embed`):**
    Проіндексований код перетворюється на векторні представлення для забезпечення семантичного пошуку.
    ```bash
    python3 main.py embed
    ```

#### Крок 3: Пошук по коду

Після завершення індексації ви можете виконувати пошук, використовуючи запити природною мовою.

```bash
python3 main.py search "Як у проєкті реалізовано підключення до бази даних?"
```

#### Крок 4: Налаштування (Конфігурація)

Ви можете керувати поведінкою інструмента через конфігураційний файл, який автоматично створюється за адресою `~/.config/code-indexer/config.yaml`.

**Налаштування моделі Ollama:**

Щоб змінити модель, яку використовує Ollama для аналізу коду, відкрийте цей файл і відредагуйте поле `ollama` в секції `models`.

**Приклад:**

```yaml
models:
  provider: auto
  embedding: all-MiniLM-L6-v2
  ollama: llama3:latest # Замініть на потрібну вам модель
```

---

#### Додаткові можливості

*   **Полегшений пошук:** Якщо вам потрібно лише шукати по вже існуючому індексу (без можливості індексації), можна використовувати легковаговий скрипт `search_index.py`. Він має менше залежностей.
    ```bash
    python3 search_index.py "ваш пошуковий запит"
    ```

*   **Глобальні команди:** Ви можете зробити команди `code-indexer` та `search-index` доступними з будь-якої директорії, виконавши скрипт `install_tools.sh`. Він розмістить виконувані файли в `~/.local/bin`.
    ```bash
    ./install_tools.sh
    ```
